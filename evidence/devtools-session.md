# US-QA-001 DevTools 验收记录

## 环境

- 微信开发者工具：Stable 2.01.2510290
- 基础库：3.17.1
- 模拟器：iPhone 12/13 Pro，86%
- 导入目录：当前 Story worktree 根目录
- AppID：`touristappid`
- 云服务：未启用
- 自定义编译模式：`qa-monday`
- 页面参数：`weekStart=2026-08-03&selectedDate=2026-08-03`

## 离线关键链

1. 清理模拟器缓存并冷启动周一计划，Network 面板选择 `Offline`。
2. 启动“熟悉器械与基础力量”，完成计时动作的开始、暂停、继续和提前完成。
3. 力量动作第 1、2 组各记录 12 次，重量留空；第 1 组完成后进入 75 秒绝对时间休息。
4. 确认休息结束后开始第 2 组；随后确认跳过两个力量动作，完成最后计时动作。
5. 总结页只填写匿名 RPE 5，体重、身体不适和备注留空；保存到本机。
6. 记录页只出现一条 `2026-08-03` 记录，显示 5 完成、2 跳过、RPE 5。
7. 统计页显示 17%、1 / 6 次和 9 分钟实际活动。

## 生命周期恢复

1. 第二次启动同一计划，将首个 5 分钟计时调整到接近截止点。
2. 使用 Actions -> Home 触发后台，越过 deadline 后使用 Actions -> Return 回前台。
3. 再次进入活跃会话，页面显示 `00:00`、`计时已结束`、`当前动作仍停留在这里`，需要显式点击“进入下一步”。
4. 关闭并重启微信开发者工具，恢复 Offline 后再次进入会话，仍显示同一动作和结束边界。
5. 重启后记录页仍只有一条已完成记录，没有产生重复记录。

## 数据控制与隐私

- 本机数据页显示生成备份、先验证/预览导入和清除本机数据入口。
- 删除、有效/无效导入、清除取消/确认在隔离自动化数据库中执行，未破坏 DevTools 视觉证据数据。
- 仓库截图不包含导出 JSON、OpenID、ownerId、token、真实姓名、联系方式或健康备注。
- 真机振动与系统屏幕常亮无法由模拟器证明；真实云环境 smoke 不包含在离线优先 V1 门禁中。

## 工具缓存观察

只执行 Clear data cache 时，旧页面内存曾触发一次 `LocalDatabase read-back validation failed`。执行 Clear All 后重新冷启动，在线和 Offline 对照均正常；重启开发者工具后也未复现。该观察未归因于产品代码，不作为通过证据使用。
