# 隐私与数据说明

练程是单用户、离线优先的小程序。本机数据库是日常使用的运行基础；CloudBase 仅在用户主动启用后保存可同步副本。

## 数据存放位置

| 数据 | 本机 | 可选云端 | JSON 导出 |
| --- | --- | --- | --- |
| 设置与便携档案 | 是 | 启用同步后 | 是 |
| 训练计划 | 是 | 启用同步后 | 是 |
| 已完成训练记录 | 是 | 启用同步后 | 是 |
| 当前训练 Session | 是，仅当前设备 | 否 | 否 |
| 设备标识、同步游标、Outbox、冲突状态 | 是 | 仅协议所需服务端状态 | 否 |
| OpenID、服务端 ownerId、密钥 | 否或仅微信运行时可见 | 服务端授权边界 | 否 |

导出包只包含便携档案、设置、计划和记录。它不包含 OpenID、认证材料、设备标识、同步游标、待同步队列、冲突状态或运行时统计投影。导入前会先校验并预览，确认前不写入本机；单个导入包上限为 5 MiB。

## 永远不要进入 Git 或日志的内容

- 真实 AppID 的本机覆盖、CloudBase 环境 ID 和任何账号标识。
- OpenID、ownerId、设备标识、确认 token、同步 cursor。
- HMAC 密钥、访问令牌、Cookie、二维码或登录截图。
- 真实体重、RPE、备注、训练计划、训练记录和导出的 JSON 正文。

仓库只允许匿名 fixture、占位符和去敏结论。`project.private.config.json`、`.env*`、本机 CloudBase 配置和常见备份文件名都被 `.gitignore` 排除。提交前运行：

```sh
npm run docs:check
bash scripts/privacy-scan.sh
git status --short
```

隐私扫描只能检查文本、清单和文件哈希，不能识别截图像素中的私人内容。截图仍需要人工确认。

## 本机清除与云端删除不是同一操作

- “清除本机数据”只删除当前设备的计划、记录、设置和本机同步状态，不会声称删除云端副本。
- “删除云端同步副本”通过服务端两阶段确认删除该账号的云端数据，本机计划、记录和设置保持不变。
- 如果希望两边都删除，应先确认没有仍需保留的数据，再分别执行云端删除和本机清除；不要把关闭同步当成删除。
- 卸载小程序或清理微信缓存不等于可审计的云端删除。

## 如何处理导出的私人 JSON

1. 只保存到自己控制且有磁盘加密或访问控制的位置。
2. 不要通过公开网盘链接、聊天群、Issue、PR、邮件正文或截图传递。
3. 排障时只提供错误码、记录数量和校验码前缀，不提供 JSON 正文。
4. 导入后如果不再需要备份，安全删除文件并清空剪贴板历史。
5. 怀疑泄露时，停止分享、删除公开副本；若同时泄露了云端密钥，立即按 [CloudBase 配置](cloud-setup.md) 的轮换步骤处理。

## 截图与验收数据

仓库中的验收截图只使用内置匿名计划、空重量/备注和固定示例 RPE。新增截图前，人工检查昵称、头像、OpenID、环境 ID、文件路径、训练数据和通知内容；日志只保留命令、来源 commit、通过数量与退出码。
